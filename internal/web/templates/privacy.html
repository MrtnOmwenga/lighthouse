Privacy

What this site records about you: very little

No cookies for reading the site, no advertising or analytics companies, and no IP addresses kept.

What is counted

Which page was viewed, when, roughly what kind of device (phone, tablet or desktop), which site linked here (its name only), and how long the page was actively read. Reading time only counts while the page is visible and you have scrolled, clicked or typed in the last minute.

It also counts a few things you may go on to do, each only as "it happened": opening a demo, opening the CV, following a link to GitHub or LinkedIn, starting an email, and reaching the end of a project's story.

If the link that brought you here carried a tag (for example, one sent with a job application), the tag is recorded with your visit and then removed from the address, and the owner is told that the link was opened.

How a visit is recognised without cookies

The server combines your IP address and browser name with a random secret that exists for one day, and keeps only the result: a pseudonym that lets it count unique visitors and follow one visit across pages. The secret is deleted when the day ends, so tomorrow you are a stranger again, and the IP address can't be worked back out of the pseudonym.

What is never counted

Browsers that send Global Privacy Control or Do Not Track are not counted at all, and the page doesn't send anything for them. Bots and the site's owner aren't counted either. The owner can mark his own browsers so they stay uncounted when he isn't signed in; that mark is a cookie, set only in his browser, when he chooses it.

Signing in

The console's sign-in is for the site's owner. If you sign in with GitHub and aren't him, the attempt is refused and recorded with your GitHub username and account number, so he can see who has tried. Starting a sandbox records nothing about you, and sets one cookie that keeps you in it for two hours.

What is public

The systems page shows how many people read about each project over the last 30 days. Any figure below five is shown only as "fewer than 5", so the public numbers can't be used to tell that one particular person visited.

How long it is kept

Visit records are deleted after 90 days. The code that does all of this is open source.
